# 禁漫天堂SDK

## 介绍

- 该项目共分为两个部分
  - 一为封装的禁漫天堂的移动端[接口](#sdk介绍)
  - 二为[**Delta Comic**](https://github.com/delta-comic/delta-comic)的禁漫天堂[插件](#插件介绍)

- sdk内置了解密与网络请求，账户管理
- 接口推断来自[禁漫天堂解包源码(Github)](https://github.com/wenxig/jmcomic-source-code)
- 该sdk封装了几乎所有的接口，如下
